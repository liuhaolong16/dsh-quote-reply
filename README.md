## 一句话
选中回答里的一段话 → 点「引用回复」→ 它落到**输入框上方的「引用」行**（和「目标」「队列」同区）。
**不用再点「插入」**：引用自动作为**上下文**随下一回合送达模型（**不进你的消息正文**），浮窗里可逐条展开/删除/清空。

> 端到端实测（2026-10-15 02:3x）：推入标记「ZQ7-紫色河马」→ **下一步模型上下文里真的出现了它**（`## 用户当前引用…`）→ 随即清空（`pending:0`）。链路：客户端 → `/quote-reply/quotes` → 宿主 pending → `systemPrompt.context` → 模型。

## 为什么不是"塞进输入框"
把引用塞进输入框，会和你要说的话**混在一起**：分不清哪句是引用、哪句是你说的，也没法统一管理。
v0.2 因此把引用做成**独立一层**：引用在浮窗里，你的话在输入框里，两者分开。

## 怎么用（v0.2）
1. 在某条回答里**选中一段**（或直接对着整条回答）；
2. 点该回答动作行里的 **「引用回复」** → 上方出现/更新 **「引用（N）」浮窗**，这条变成 **引用一/二/…**；
3. 浮窗里可以：**点标题折叠/展开** · 逐条**删除** · **清空** · **单条「插入」或「全部插入输入框」**（临时逃生通道，
   发出去时就会带上）。

## 下一阶段（已探明可行路径，尚未做）

2. **发送后折叠显示**：引用以机器可读块随消息发出（模型能看到），你的那条消息里**用样式隐去原块**，
   在该回合尾部显示一行 **「引用」**（与「已完成 用时…」同款、可点开）→ 逐条列出 引用一/二/… 与内容。
   *为什么不直接替换 `user` 消息渲染器*：那是 `shadows-shipped-ui`（会接管官方渲染、丢掉官方后续特性），风险不值得。

## 技术要点（改它之前先读）
- **两个槽位**：`conversation.input.dock`（输入框上方浮窗，order 30 —— 现有占用者是 `goal(10)`/`queue(20)`）
  与 `conversation.chat.assistant-actions`（每条助手消息的动作条，order 30）。
- **引用层是模块级 `Map`（按 sessionId 分桶）**：要在两个槽位之间共享，且切会话/重挂载不能丢。
  暴露 `__quote`（add/remove/clear/list/cn）供自检直接验证行为。
- 「引用回复」按钮必须 `onMouseDown: e => e.preventDefault()`，否则按下会先塌陷选区、拿不到"选中那段"。
- `apply` 全程不抛（服务读取经 `safe()`、每块注册各自 `guard()`），失败只留一行 `console.error`。

## 它长什么样 / 怎么用

1. 在某条已完成的回答里**选中你想回应的那段文字**（拖选即可）；
2. 在这条回答的动作行里点 **「引用回复」**（和自带的 反馈 / 跳转 按钮并排）；
3. 输入框里会出现形如

   ```
   > 你选中的那段原文

   ```
   光标在下面，直接接着写你的问题就行。

**没选中任何文字时**，点它会**整条引用**该回答（并在旁边提示"未选中文字，已整条引用该回答"）——
这样"就想对整条回应"的场景也是一下点击。

## 它**不**做什么（边界）

- **不自动发送**：只把引用放进输入框，发不发、怎么改都由你。
- **不碰你没选的内容**：引用块只含你选中的那段（超长会截断并写明"已截断，原长 N 字"）。
- **插入失败不静默丢**：如果你点击的那一瞬间草稿被改动（或被别的东西占用），插入会被宿主拒绝；
  此时引用**原样保留在按钮旁**，并给一个「复制保留的引用」——绝不悄悄丢弃你的操作。

## 技术要点（给后来改它的人）

- 落点：客户端槽位 **`conversation.chat.assistant-actions`**（"Ordered actions for one finalized assistant message"，
  `ownerProps = { messageId }`，standardProps 自带 **`inputActions`**）。本插件取 `order = 30`
  （排在自带 `mf#feedback(10)`、`dsh-context#context-jump(20)` 之后）。
- 插入正门：**`inputActions.captureInsertion()` → `inputActions.insertText(text, span)`**。
  后者**仅在草稿版本未变且编辑器允许编辑时**插入一次**可撤销**的编辑，失败返回 falsy。
- **`onMouseDown` 必须 `preventDefault()`**：否则按下按钮会先塌陷选区，"选中一段再点"就永远拿不到那段话。
- 取文本：**选区优先**；无选区时按 `messageId` 找消息节点（试 `data-message-id` 等若干属性名）取正文兜底。
- 宿主半体（`lib/index.js`）**故意为空**，只保证包根可被 import ——
  （踩过：宿主半体里误写成 Markdown 标题 + 孤立 `*/`，宿主直接报 `failed to import`，整个插件不工作。）
- `apply` 全程不抛：服务读取经 `safe()`、每块注册各自 `guard()`，失败只留一行 `console.error`，
  绝不把异常抛进加载器（这是 2026-10-13 一次整站白屏换来的纪律）。
